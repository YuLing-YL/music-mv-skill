## Filling Rules

1. **Shot ID**: `SH` + 3-digit incrementing number, continuous across the whole scope.
2. **Start-End**: First shot starts at 00:00.00, last shot ends at song end (or clip end); no gaps, no overlaps between shots.
3. **Section**: Intro / Verse A / Verse B / Pre-chorus / Chorus / Interlude / Bridge / Outro (前奏/主歌/预副歌/副歌/间奏/桥段/尾奏).
4. **Lyrics**: The lyric lines for this time span; use "(no lyrics)" for instrumental parts.
5. **Visual Content**: Describe the core imagery; if there is a plotline, advance it here (story arc mapped to sections); if there are characters, keep their design consistent with the locked style throughout.
6. **Camera**: push / pull / pan / track / orbit / whip pan / static (推/拉/摇/移/环绕/甩镜/固定).
7. **Beat Trigger**: Choose from the fixed rules — flash, zoom-in, particle burst, low-freq flow, slow push + gradient, faster cutting, slow camera movement, none (闪光/放大/粒子爆发/低频流动/慢推渐变/加快切镜/慢运镜/无).
8. **Transition**: hard cut / cross-dissolve / flash-white / fade-to-black / slide (硬切/叠化/闪白/黑场/滑动). Chorus favors hard cuts; quiet sections favor cross-dissolves.
